LASSO and Relaxed LASSO Using CCD for Air-Pollution Data

This repository contains the source code accompanying the manuscript “LASSO and Relaxed LASSO for Prediction and Variable Selection in Indonesian Annual Air-Pollution” by Maulida Yanti, Putri K. Nasution, and Enita Dewi T.

The manuscript is currently submitted to Enthusiastic: International Journal of Applied Statistics and Data Science.

The code implements LASSO and Relaxed LASSO using the Cyclic Coordinate Descent (CCD) algorithm for prediction and variable selection in Indonesian annual air-pollution time-series data.
